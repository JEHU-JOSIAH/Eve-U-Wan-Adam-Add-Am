# Eve U Wan Adam Add Am — V8.1 Editorial Transformation

This release is an editorial transformation pass over the 120-node V8 scenario bank.

Each node now carries: objective, hidden tension, self-deception trap, evidence to watch, mirror question, long-term lens, transformation move, and an explicit rule not to reward answers merely because they sound Christian.

The goal is to make scenarios expose beliefs under changing life circumstances, reversals, consequences, and repair—not simply test preferred answers.
